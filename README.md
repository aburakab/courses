> Follow these simple steps to add your profile to the course repository using Visual Studio Code and submit a Pull Request !

## 1. Fork the Repository
> Click on the **Fork** button at the top-right corner of this repository page to create a copy under your own GitHub account.

<p align="left">
 <img src="screenshots/Fork.webp" width="1400" alt="Step 1: Fork Repository">
</p>

---

## 2. Clone Your Forked Repository Locally
> Go to your GitHub profile, open your forked repository, copy its HTTPS/SSH URL, and clone it to your local machine using VS Code (or your terminal):

<p align="left">
   <img src="screenshots/Clone.webp" width="1400" alt="Step 2: Clone Your Forked Repository">
</p>

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/REPOSITORY_NAME.git
```

## 3. Open VS Code & Edit the README.md File
> Open the project folder in Visual Studio Code, navigate to the README.md file, copy the student row template, and fill in your personal details (Avatar, Full Name, LinkedIn URL).

```Markdown

| <img src="[https://github.com/YOUR_GITHUB_USERNAME.png](https://github.com/YOUR_GITHUB_USERNAME.png)" width="40" style="border-radius: 50%;"> | **Your Full Name** | [![GitHub](https://img.shields.io/badge/GitHub-24292e?style=for-the-badge&logo=github&logoColor=white)](https://github.com/YOUR_GITHUB_USERNAME) [![LinkedIn](https://img.shields.io/badge/LinkedIn-0077B5?style=for-the-badge&logo=linkedin&logoColor=white)](YOUR_LINKEDIN_URL) |

```
<p align="left">
   <img src="screenshots/EDIT.webp" width="1400" alt="Step 3: Edit the README.md File">
</p>

## 4. Commit, Push Your Changes & Open a Pull Request
> Save the file, commit your changes, push them to your GitHub fork, then return to the original repository and click Compare & pull request to submit your contribution !

```bash
git add README.md
git commit -m "Add [Your Full Name] to contributors list"
git push origin main
```
